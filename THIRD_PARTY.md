# Third-party dependencies

RabbitHole has no approved project license yet. MIT is a proposed future choice, not an applied grant.

Key dependencies: React/React DOM (MIT), React Flow @xyflow/react (MIT), Express (MIT), better-sqlite3 (MIT), Zod (MIT), Mozilla Readability (Apache-2.0), and Model Context Protocol TypeScript SDK (MIT). Exact installed versions and transitive dependencies are in package-lock.json; license texts ship with their node_modules packages. Preserve applicable notices when distributing builds. The included THIRD_PARTY_LICENSES.txt is generated from the installed packages used by the build, including development dependencies for completeness.
