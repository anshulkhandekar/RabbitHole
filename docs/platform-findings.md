# Platform findings — checked October 24, 2026

| Source                                                                                                                           | Finding and implementation consequence                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Superhuman MCP guide](https://coda.io/packs/build/latest/guides/blocks/mcp/)                                                    | Hosted Streamable HTTP, tools only, no streamed response dependency. Connector generation from Packs page is supported. Static bearer authentication and declared network domains are supported. Use one hosted MCP endpoint and generated connector.                                        |
| [MCP confirmations](https://coda.io/packs/build/latest/guides/blocks/mcp/#user-confirmation-for-actions)                         | A tool is treated as a state-changing action unless readOnlyHint is true. SaveSessionAnalysis truthfully advertises false.                                                                                                                                                                   |
| [Actions](https://coda.io/packs/build/latest/guides/blocks/actions/)                                                             | Go prompts for confirmation for actions. Scheduling does not establish approval-free writes.                                                                                                                                                                                                 |
| [Agent builder](https://help.superhuman.com/hc/en-us/articles/47453035724685-Create-and-configure-agents-with-the-agent-builder) | Lists scheduled, writing, mail, and Slack triggers. Agent tools/access and instructions are set in Go UI. No public external invoke API was found here. Brief's organizer confirmation establishes that architectural constraint.                                                            |
| [MCP Apps compatibility](https://coda.io/packs/build/latest/guides/blocks/mcp/#mcp-apps)                                         | Apps render in the Go web client, not browser/desktop clients. Deferred.                                                                                                                                                                                                                     |
| [MV3 lifecycle](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)                         | Worker state cannot rely on global variables surviving. Queue and session state are persisted in storage.local; alarms retry sync. In-memory chain only serializes live mutations.                                                                                                           |
| [Side panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)                                               | sidePanel permission and explicit panel behavior. Same bundled React UI serves full tab, options, and side panel.                                                                                                                                                                            |
| [Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)                                 | Dynamic scripts in isolated world, main frame only; send bounded data to worker.                                                                                                                                                                                                             |
| [Permissions](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)                                 | Optional host permissions require user grant; they permit cross-origin backend fetch and article injection. Broad runtime website access supports navigation across a trail, but worker scopes recording to included tab IDs. No tabs, history, cookies, webRequest or incognito permission. |
| [Storage](https://developer.chrome.com/docs/extensions/reference/api/storage)                                                    | storage.local persists and is restricted to trusted contexts. Browser local storage is finite, not an unlimited archive. Export/delete old sessions.                                                                                                                                         |
| [Commands](https://developer.chrome.com/docs/extensions/reference/api/commands)                                                  | Default Alt+Shift+H can be reassigned in chrome://extensions/shortcuts. Context-menu fallback is present. Actual OS shortcut conflicts need manual check.                                                                                                                                    |
| [Official MCP TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk)                                            | Installed 1.32.2; implementation uses server/mcp.js and StreamableHTTPServerTransport. Official client round-trip tested.                                                                                                                                                                    |
| [React Flow](https://reactflow.dev/learn)                                                                                        | @xyflow/react 12.12.0, MIT. Deterministic grid positions avoid graph physics overhead.                                                                                                                                                                                                       |
| [Readability](https://github.com/mozilla/readability)                                                                            | @mozilla/readability 0.6.0, Apache-2.0. Parse a sanitized document clone on included article pages; render plain text, never captured HTML.                                                                                                                                                  |
| [Render persistent disks](https://render.com/docs/disks)                                                                         | Disk is a paid-service feature. Only mounted paths survive restart/redeploy; SQLite must be on /var/data. Default ephemeral filesystem is unsuitable. One instance only.                                                                                                                     |

The docs.superhuman.com Packs URL could not be fetched by the research tool; coda.io's official documentation rendered with Superhuman branding. The supplied competition slides were not attached, so the October 31 deadline and submission rules are taken from the user's brief, not independently verified organizer documents.

Installed versions are locked in package-lock.json. Initial dependency scan found a high-severity Zod advisory; upgraded to 4.6.7, then npm audit reported zero known vulnerabilities. Re-run before submission.

The signed-in account was also checked: its workspace exposes Packs → Create an MCP Connector, and the first dialog requires an MCP Server URL. Creating/installing a live connector is pending hosted deployment and authentication.
